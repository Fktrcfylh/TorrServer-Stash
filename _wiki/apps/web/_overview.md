# TorrServer web UI

**Type:** core
**Root:** `/web`
**Entry point:** `web/src/index.jsx` → `web/src/components/App/index.jsx`

## Purpose
Single-page React admin UI served by the Go server: torrent list (cards), torrent details dialog, add dialog, settings. Talks to the backend only via `POST` JSON actions on `/torrents`, `/cache`, `/settings`, etc.

## Features
- [Torrent details dialog](torrent-details-dialog.md) — details view, file table (+ predownload Disk column), torrent actions (+ predownload pin block with off confirm), cache map, polling; also covers the `TorrentCard` predownload badge and the `DefaultPinNext` settings field

Not ingested yet: `Add` dialog, `Settings` (only the pattern + `DefaultPinNext` cited), `App` shell (only the list polling is cited). `TorrentCard` partially cited (dialog host, memo comparator, `PinBadge`) in [Torrent details dialog](torrent-details-dialog.md).

## Tech
- React 17 (`web/package.json:18`), CRA `react-scripts` 4.0.3 (`web/package.json:26`), Material-UI v4 (`web/package.json:6`), styled-components, react-query v3 (`web/package.json:25`), axios, i18next (`web/package.json:11`)
- Imports resolve from `src` (`web/jsconfig.json:3`)

## How to run
`cd web && yarn install --frozen-lockfile && yarn start` (dev) / `yarn build`; lint `yarn lint` (`web/package.json:31-37`). Node ≥17 needs `NODE_OPTIONS=--openssl-legacy-provider` (CRA 4 / webpack 4). Gate: [CI / test gate](../../concepts/ci-test-gate.md).

## Notes
- API host helpers: `web/src/utils/Hosts.js:3-19`; torrent list polled every 1000 ms (`web/src/components/App/index.jsx:49-54`).
- Data shape: [Torrent status JSON](../../concepts/torrent-status-json.md).
- Predownload (pin) UI is derived from polled status fields (`pin_*`, file `pinned/completed/downloaded`); the only write is `POST /torrents {action:'pin'}` followed by `invalidateQueries('torrents', …, { cancelRefetch: true })` — server side: [Torrent pin](../server/torrent-pin.md).
- Embedded build `server/web/pages/template/*` is regenerated by maintainer "update static web" commits, not in feature PRs ([CI / test gate](../../concepts/ci-test-gate.md)).
