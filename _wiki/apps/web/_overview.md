# TorrServer web UI

**Type:** core
**Root:** `/web`
**Entry point:** `web/src/index.jsx` → `web/src/components/App/index.jsx`

## Purpose
Single-page React admin UI served by the Go server: torrent list (cards), torrent details dialog, add dialog, settings. Talks to the backend only via `POST` JSON actions on `/torrents`, `/cache`, `/settings`, etc.

## Features
- [Torrent details dialog](torrent-details-dialog.md) — details view, file table, torrent actions (+ NAS predownload checkbox with untick confirm, state + progress), cache map, polling; also the `TorrentCard` NAS badge, flagged delete and comparator, and `RemoveAll` (`wipe`)
- [NAS settings](remote-downloader-settings.md) — Settings tab "NAS": remote downloader type (Transmission/qBittorrent)/URL/credentials/download dir + test connection

Not ingested yet: `Add` dialog, `Settings` (only the save pattern + NAS tab cited), `App` shell (only the list polling is cited). `TorrentCard` partially cited in [Torrent details dialog](torrent-details-dialog.md).

## Tech
- React 17 (`web/package.json:18`), CRA `react-scripts` 4.0.3 (`web/package.json:26`), Material-UI v4 (`web/package.json:6`), styled-components, react-query v3 (`web/package.json:25`), axios, i18next (`web/package.json:11`)
- Imports resolve from `src` (`web/jsconfig.json:3`)

## How to run
`cd web && yarn install --frozen-lockfile && yarn start` (dev) / `yarn build`; lint `yarn lint`. Node ≥17 needs `NODE_OPTIONS=--openssl-legacy-provider` (CRA 4 / webpack 4). Gate: [CI / test gate](../../concepts/ci-test-gate.md).

## Notes
- API host helpers: `web/src/utils/Hosts.js:3-21`; torrent list polled every 1000 ms (`web/src/components/App/index.jsx:49-51`).
- Data shape: [Torrent status JSON](../../concepts/torrent-status-json.md).
- NAS UI is derived from polled `remote_*` status fields; writes are `POST /torrents {action:'remote'}` (then `invalidateQueries('torrents', …, { cancelRefetch: true })`), `rem`/`wipe` (awaited when they can fail), and `POST /settings {action:'test_remote'}` — server side: [Remote download](../server/remote-download.md).
- Embedded build `server/web/pages/template/*` is regenerated by maintainer "update static web" commits, not in feature PRs ([CI / test gate](../../concepts/ci-test-gate.md)).
